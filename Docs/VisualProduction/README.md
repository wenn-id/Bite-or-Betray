# Bite or Betray: visual production

`Visual_Target.png` is the approved overall visual reference. The PDF describes the Blender-to-Unity/Quest 3 roadmap.

`Cast_MultiView_v1/` contains the six supporting characters as individual full-body PNGs on white backgrounds, including their front references. Five characters have all four views; the red grouch has front, back, and right views. Its left view was rejected by the image generator and remains unavailable. Prompt files and the original generation manifest are included for provenance; paths in those records refer to the original local workspace.

These are design references, not Unity-ready meshes. The current imported game assets are under `Assets/BiteOrBetray/Art3D/` and `Assets/BiteOrBetray/VisualPrototype/`. Blender source and production scripts are under `Tools/Blender/`.
